# 인과 시장 엔진

## 목적과 구성

인과 시장 엔진은 뉴스의 기본 가격 충격을 모든 대상에 같은 방향으로 복사하지 않고, 사건이
바꾼 경제 변수가 비용·수요·투자 경로를 거쳐 산업과 종목에 도달하도록 계산한다. 엔진은
시계, 난수, 가변 상태를 갖지 않는 순수 함수이며 같은 신호와 종목 카탈로그에는 항상 같은
결과를 반환한다.

구성 요소는 다음과 같다.

- `CausalSignalSeed`: 저장되는 사건의 시작 경제 요인, 상승·하락 방향, 강도와 신뢰도
- `CausalMarketEngine`: 경제 요인 그래프의 감쇠 가중 전파와 경로 합성
- `CausalExposureCatalog`: 경제 요인에서 산업·세부 산업·종목으로 가는 마지막 노출 간선
- `ResolvedEventImpact`: 편집자 경로, 인과 그래프, 스코프 fallback을 한 가격·뉴스 판정으로 통합
- `NewsUiProjection`: 종목별 관련 기사와 인과 경로, 상대민감도, 신뢰도를 안정적으로 투영

`StockDefinition`에는 인과 필드를 추가하지 않았다. 정적 노출은 별도 카탈로그에 두므로 저장
파일마다 동일한 종목 노출이 반복되지 않는다. 삼성전자, 카카오게임즈, MSFT, AAPL, NVDA,
XOM처럼 복수 사업을 가진 회사는 회사별 override로 일반 산업 노출을 대체한다.

## 전파 공식

시작 신호의 부호 포함 강도를 `s`, 감쇠율을 `λ`, 경로의 간선 수를 `|p|`, 각 간선
가중치를 `w_e`라고 하면 단순 경로 하나가 종목에 주는 기여는 다음과 같다.

```text
c_p = s × λ^|p| × ∏(e ∈ p) w_e
```

현재 `λ`는 0.72로 1보다 작다. 산업·종목 노출은 마지막 간선으로 계산한다. 동일 종목에
도달한 경로 기여는 부호를 유지해 합산하므로 서로 반대인 경로는 상쇄된다. 합성값의 부호가
가격 방향이고 절댓값이 같은 사건 안에서 사용하는 상대민감도다. 신뢰도는 경로 길이마다
별도로 감쇠한 뒤 각 경로의 절대 기여를 가중치로 평균한다.

반환 결과에는 다음 정보가 들어 있다.

- 합성 방향과 부호 포함 민감도
- 가격 충격 합성에 쓰는 상대민감도
- 경로 길이를 반영한 신뢰도
- 경제 요인부터 산업 또는 회사까지 이어지는 정렬된 trace와 각 경로 기여
- 직접 종목, 세부 산업, 산업 중 가장 구체적인 최종 노출 수준

## 안정성과 상한

그래프가 확장되어도 결과가 폭주하지 않도록 다음 제한을 함께 적용한다.

- 한 경로에서 경제 요인을 다시 방문하지 않는다.
- 경제 요인 간 최대 깊이는 6이다.
- 모든 요인 간선과 종목 노출 가중치의 절댓값은 1 이하이다.
- 절대 기여가 0.004보다 작은 경로는 더 이상 확장하지 않는다.
- 경로 하나의 절대 기여는 1, 한 종목의 합성 상대민감도는 1.5로 제한한다.
- UI와 진단에는 절대 기여가 큰 순서로 최대 8개 trace만 보존한다.

따라서 유한 깊이 제한을 제거하더라도 `λ < 1`과 가중치 상한 때문에 긴 경로는 기하급수적으로
작아진다. 현재 구현은 여기에 단순 경로와 유한 깊이를 동시에 적용해 순환 그래프에서도 계산량과
결과를 명시적으로 제한한다.

## 영향 판정 우선순위와 범위

종목 하나의 최종 영향은 다음 우선순위로 결정한다.

1. 일치하는 `EventImpactInsight` 편집자 경로 또는 종목 override
2. 일치하는 편집자 경로가 없을 때 causal graph 결과
3. 둘 다 없고 정책이 허용할 때 기존 event scope fallback
4. 어느 경로에도 포함되지 않으면 무영향

따라서 기존 편집자 경로의 방향과 민감도는 바뀌지 않는다. `EXPLICIT_PATHS_ONLY`도 구조화된
causal seed를 명시적인 전파 출발점으로 인정하지만 일반 scope fallback은 사용하지 않는다.

범위가 시장이나 국가인 사건은 해당 상장시장 또는 ETF 기초시장 노출 안에서만 인과 전파된다.
개별 종목 사건도 지정 종목과 그 종목을 명시적으로 기초자산으로 가진 상품에만 제한된다.
산업 사건은 공급망 특성상 다른 산업으로 전파할 수 있고, 글로벌 사건은 전체 시장을 출발점으로
사용한다. 전역 `riskSentiment`는 글로벌 사건만 변경한다. 시장 단위 투매 사건의 심리가 다른
국가·시장에 전역 매크로 값으로 새지 않고 event coverage 경로로만 전달되는 이유다.

## 가격 합성

인과 엔진은 독립된 예상 주가를 만들지 않는다. `EventShockCalculator`가 사건의 기본
`shockReturn`과 `hourlyDrift`에 종목별 방향·상대민감도를 적용하고, `PriceEngine`이 이를 시장,
산업, 금리·물가, 성장·신용, 환율, 개별 난수 항과 로그수익률 기준으로 합성한다.

```text
종목 수익 ≈ 시장 항 + 산업 항 + 거시 항 + 이벤트 항 + 개별 항
```

각 항의 부호와 크기가 독립적이므로 좋은 실적 뉴스가 있어도 같은 시간의 시장 급락이나 산업
악화 항이 더 크면 최종 가격은 하락할 수 있다. 반대로 악재가 있어도 시장·산업 상승이 더 크면
가격이 오를 수 있다. 뉴스 UI의 방향은 사건 경로의 방향이지 최종 수익률 보장이 아니다.

ETF의 레버리지·인버스 배율은 노출 카탈로그나 인과 엔진에서 곱하지 않는다. 인과 엔진은
기초자산 기준 민감도만 반환하고 `PriceEngine.eventLogReturn`이 상품 배율을 정확히 한 번
적용한다. 종목 자체의 운용·발행사 사건은 기존 direct-product 경로로 분리한다.

## 원유 가격 예시

`oil_supply_shock`은 `원유 가격 상승` 신호를 시작한다.

```text
원유 가격 상승
├─ 에너지 생산자 현금흐름 증가 → XOM 등 긍정
├─ 운송 연료비 상승 → 해운·항공·물류 부정
├─ 석유화학 투입 원가 상승 → 화학 마진 부정
│  └─ 플라스틱·포장재 원가 상승 → 플라스틱 사용 소비재 부정
└─ 가계 에너지 부담 증가
   └─ 소비 수요 감소 → 경기소비재·유통 부정
```

에너지, 운송, 경기소비재에 이미 존재하는 편집자 경로가 먼저 적용된다. 그 밖의 화학 투입원가,
포장재, 소비 수요 경로는 causal graph가 보완한다. XOM은 통합 에너지 사업구성을 반영한 종목
override가 일반 에너지 기업 경로보다 높은 구체성으로 적용된다. `oil_price_collapse`는 같은
그래프의 시작 방향만 반대로 두어 생산자는 부정, 연료·원가 부담 대상은 긍정으로 계산한다.

## 게임 수요 예시

`game_demand_slowdown`은 `게임 소프트웨어 수요 하락`에서 시작한다.

```text
게임 소프트웨어 수요 하락
└─ 고사양 PC 수요 하락
   └─ 컴퓨팅 하드웨어 수요 하락
      └─ 반도체 수요 하락
```

카카오게임즈는 게임 사업 직접 노출이 커 가장 강하게 반응한다. MSFT는 게임·클라우드·업무
소프트웨어가 섞여 직접 영향이 완화된다. AAPL과 삼성전자의 하드웨어 영향은 한 단계 이상
감쇠하고, NVDA와 삼성전자의 반도체 영향은 더 긴 경로를 지나므로 더 약해진다. 반대 방향의
`game_hit_cycle`도 같은 사업구성 차이와 감쇠를 사용한다.

## 저장과 뉴스 투영

저장 스키마 11은 모든 이벤트에 `causalSignals` 배열을 저장한다. 복원 전에 각 signal 객체가
정확히 `factor`, `direction`, `strength`, `confidence` 필드만 갖는지 검사하고, enum 이름과
유한 숫자 여부를 확인한다. 상태 validator는 강도·신뢰도 범위, 같은 factor의 중복, 생성
템플릿 payload와의 일치까지 다시 검증한다.

뉴스 projection의 `storiesForStock(stockId)`는 직접 대상, 구체성, 현재 활성 상태, 최신 발표
시각, 이벤트 ID 순으로 안정 정렬한다. `NewsRelatedStockUi`는 인과 trace label,
`relativeSensitivity`, `confidence`를 제공하며 원인 설명도 가장 큰 인과 경로를 사용한다.

## 확장 방법

새 인과 사건을 추가할 때는 다음 순서를 따른다.

1. 기존 경제 요인으로 표현할 수 없을 때만 `CausalEconomicFactor`를 추가한다.
2. `CausalMarketEngine.edges`에 부호와 절댓값 1 이하의 간선을 추가한다.
3. 실제 수익 구조가 연결되는 산업·세부 산업 노출을 `CausalExposureCatalog`에 추가한다.
4. 복합기업 차이가 중요할 때만 시장 접두사를 포함한 stock ID override를 추가한다.
5. `EventTemplate.causalSignals`에 시작 factor, 방향, 0 초과 1 이하 강도·신뢰도를 선언한다.
6. 기존 편집자 판단을 반드시 보존해야 하는 대상은 `EventImpactInsight`로 더 구체적으로 선언한다.
7. 시장·국가·종목 범위가 의도 밖으로 확장되지 않는지와 ETF 배율이 한 번만 적용되는지 확인한다.

간선을 추가할 때 라벨이 비슷하다는 이유만으로 연결하지 않는다. 매출, 수요, 비용, 자금조달처럼
방향을 설명할 수 있는 경제 관계와 종목의 실제 사업구성이 있어야 한다.
