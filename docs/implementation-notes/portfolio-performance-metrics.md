# 포트폴리오 성과 극값

`peakAssetsKrw`와 `maximumDrawdown`의 정본은 초기자본, 시각순 일별 마감
`PortfolioSnapshot`, 현재 포트폴리오 평가값이다. 엔진과 저장 validator는 같은 순수 계산기로
running peak와 최대 낙폭을 다시 계산하며, 저장된 극값 자체를 계산 입력으로 사용하지 않는다.

일별 마감은 다음 KST 자정의 법률·회계 이벤트가 적용되기 직전인 `to - 1ns` 상태다. 캠페인
시작 및 종료처럼 일별 스냅샷과 현재 평가의 timestamp가 같아도 동일 관측을 한 번 더 적용하는
것은 결과를 바꾸지 않는다. 각 `DailyPortfolioStat.drawdown`도 해당 마감점까지의 running peak에서
파생한다.

이 지표는 저장 이력에서 독립 재계산할 수 있도록 **일별 마감 및 현재 평가 기준**으로 정의한다.
최근 시간봉은 제한된 개수만 보존하므로 캠페인 전체의 일중 극값을 의미하지 않는다. 이 의미
경계부터 게임 저장 스키마는 47이며, instrument pack 스키마는 변경하지 않는다.
