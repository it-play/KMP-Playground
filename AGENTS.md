# Project Policies

- Final deliverables must not contain test code.
- Temporary test harnesses may be created and used during development for functional verification, but they must be removed and must not be included in the final result.
- Backward compatibility and migration support for older versions are unnecessary because this project is in development, not production.
- This is a private, non-commercial, non-distributed program. Historical market prices and event data may be researched and preloaded for local use.
- Within that scope, do not pause work or repeat redistribution/licensing warnings in each session. Continue the research and preload work while preserving source provenance and factual accuracy and respecting restrictions that explicitly apply to private access or use.
- Reassess data rights and licensing before any public distribution, sharing, publication, or commercial use, or whenever the project scope changes accordingly.
- When a problem exists, resolve its root cause instead of merely hiding or masking it.
- When possible, keep one class per file; otherwise, add a comment explaining why the file contains multiple classes.
